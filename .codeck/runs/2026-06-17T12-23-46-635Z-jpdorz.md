# Codeck: AI 命令行路由与上下文助手

**一句话解释**：Codeck 是一款本地 AI CLI 路由器，它能将 IDE AI 助手（如 Codex）的复杂任务智能分发给最合适的本地 AI 命令行工具（如 Claude Code、Gemini CLI）去执行。

### 解决的问题
在日常开发中，主 AI（比如 Codex）很容易遇到上下文超载、Token 超出预算，或者并不擅长某些特定长任务的情况。Codeck 就像一个“任务路由器”，帮主 AI 将特定任务自动分配给最擅长的本地专属 AI 工具，并精准打包项目结构、开发规范等上下文。避免无用代码占满窗口，帮你省时又省钱。

### 安装
确保本地已安装 Node.js，拉取代码后在项目根目录执行：
```bash
npm install
npm run build
npm link
```
*(注：如果链接时遇到权限报错，可尝试 `sudo npm link --unsafe-perm`)*

### Codex MCP 接入
Codeck 原生支持 MCP（模型上下文协议）。在终端运行以下命令即可将它接入 Codex：
```bash
# 强烈推荐使用绝对路径，避免环境变量差异导致找不到命令
codex mcp add codeck -- node /你的完整路径/Codeck/dist/index.js mcp start
```

### 常用命令
- `codeck init`：在当前开发项目中初始化配置（生成 `.codeck` 文件夹）。
- `codeck doctor`：体检命令，检查本地 AI 工具环境是否就绪。
- `codeck list`：列出配置好的所有执行器（Executors）。
- `codeck last`：查看最后一次 AI 任务的完整执行结果。

### Executor 示例
你可以根据任务类型，把任务委派给不同的“执行器（Executor）”：
- **咨询问题**：`codeck ask claude_architect "解释下目前项目 src 目录下的架构"`
- **委托写代码**：`codeck delegate codex_implementer "编写 utils 的测试用例"`
- **多模型打擂台**：`codeck compare claude_architect,gemini_frontend "评审这个 PR，谁给的建议更好"`

### Gemini Web 说明
就算你本地没有配置复杂的 API Key 也没关系！
输入下面这行命令，Codeck 会帮你打包好所有相关的项目代码和上下文，自动复制到你的系统剪贴板，并打开 Gemini 的网页版：
```bash
codeck ask gemini_web "帮我写一个基础的前端页面"
```
你只需要在弹出的网页输入框里 `Ctrl+V` (或 `Cmd+V`) 粘贴，就能带着完整的项目背景向 Gemini 提问，超级简单。

### 注意事项
1. **配置绝对路径**：在各类客户端（Codex、Cursor 等）中配置 MCP 时，最好使用 `node /绝对路径/dist/index.js mcp start`，这能完美避开系统的环境变量缺失问题。
2. **安全隔离机制**：为了保护你的项目，在 MCP 模式下会默认拦截所有“写文件”或“执行终端命令”的高危操作。如果你需要执行，请回到本地终端里手动用 `codeck` 确认执行。
3. **环境被强杀**：如果在某些 IDE 沙箱里，全局命令 `codeck` 被系统直接终止退出（如提示 SIGKILL），请退回最原始的方法，直接使用 Node 显式运行：`node dist/index.js <命令>`。
